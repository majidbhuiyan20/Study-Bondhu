# 28 — Bangla + English

See `localization_patterns.md` for the technical guide. This file is the
**content** policy.

## Translation style

Write natural Bangla, not literal translations:

| English                  | Bangla                |
| ------------------------ | --------------------- |
| Today's Tasks            | আজকের কাজ              |
| Study Progress           | পড়ার অগ্রগতি             |
| Revision Due             | আজ রিভিশন দিতে হবে         |
| Upcoming Exam            | আসছে পরীক্ষা             |
| Weak Topics              | যেগুলো কঠিন লাগছে          |
| Add Subject              | বিষয় যোগ করো            |
| Keep going!              | চালিয়ে যাও!              |
| Goal reached!            | লক্ষ্য পূরণ হয়েছে!          |
| What should I study now? | এখন কী পড়বে?            |

## Font

`TriooBangla` (Tiro Bangla) — single font for both English and Bangla.

## Date format

- English: "Monday, 17 August"
- Bangla: "সোমবার, ১৭ আগস্ট"

Use `intl` with the active locale.

## Currency

`৳` (Bangladeshi Taka) — no decimal for whole amounts.
