# 09 — Exam Preparation Mode

A dedicated screen that opens for each upcoming exam. Shows the student's
readiness at a glance and prescribes what to do today.

## Header

```
Operating System Exam
5 days left
```

## Weak Topics section

List of topics for the subject with `status == weak`, sorted by last
revision date (least recent first).

```
🔴 Deadlock
🔴 Memory Management
🟡 Synchronization
```

## Recommended Today

A time-budgeted plan: pick the most-urgent items first.

```
� Deadlock          — 40 min
🟡 Synchronization   — 25 min
🟢 FCFS revision     — 15 min
```

The plan is generated by the same engine as
`11_what_to_study_now.md`, but constrained to the exam's subject.

## Files

```
lib/features/exams/
└── views/exam_preparation_view.dart
```

This is a derived view — it reads from multiple providers (subjects,
topics, syllabus, revisions, study sessions) and computes the plan on the
fly. No new ViewModel needed; use `Provider` for the computation.
